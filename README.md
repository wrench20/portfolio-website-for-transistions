# Tebi Njeik — Portfolio

Personal portfolio site for Tebi Njeik, a full-stack developer from Cameroon. Built with **Next.js**, **React**, **TypeScript**, and **GSAP**.

---

## Tech Stack

- **Next.js** (App Router) + **React** + **TypeScript**
- **GSAP** for scroll-driven animation
- **Lenis** for smooth scrolling

---

## Getting Started

### 1) Install

```bash
npm install
```

### 2) Run locally

```bash
npm run dev
```

### 3) Build

```bash
npm run build
```
